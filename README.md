# Sparxx947.github.io

Zwei schlichte Seiten für die private Google-OAuth-App „rclone PC-JENS“. Google verlangt für den
Produktionsmodus eine öffentliche Startseite und eine Datenschutzerklärung. Ohne Produktionsmodus
verfällt die Anmeldung alle 7 Tage. Eingerichtet wird die App mit `cloud-anmelden --google-client`
(homelab-werkzeuge #210).
